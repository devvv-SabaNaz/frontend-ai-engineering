# AI Workflow Comparison

## Feature
Settings Form

## Round 1 - Vague Prompt

### Prompt
Create a responsive settings form using HTML, CSS, and JavaScript.

### Result
The AI generated a basic settings form with simple input fields and minimal validation.

### Strengths
- Fast to generate
- Clean layout
- Functional form

### Weaknesses
- No accessibility improvements
- Basic validation only
- Limited user experience

---

## Round 2 - Precise Prompt

### Prompt
Create a responsive settings form using HTML, CSS, and JavaScript.

Requirements:
- Include Full Name, Email, Password, and Theme selection.
- Add client-side validation.
- Show clear error messages.
- Use semantic HTML.
- Make the layout mobile responsive.
- Add accessibility labels.
- Write clean, well-commented code.

### Result
The AI produced a more polished form with validation, accessibility improvements, responsive design, and cleaner structure.

### Comparison

| Feature | Vague Prompt | Precise Prompt |
|---------|--------------|----------------|
| Validation | Basic | Complete |
| Accessibility | Limited | Improved |
| Responsive Design | Basic | Better |
| Code Quality | Average | Clean and organized |

## AI Mistake I Caught

The initial AI response missed accessibility labels and proper validation. I reviewed the code and corrected those issues.

## Conclusion

Using a precise prompt produced a significantly better result with cleaner code, improved accessibility, and a better user experience.
